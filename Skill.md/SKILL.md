# Data Ethics Tool Skill

## Purpose
Provide guidance for using the data ethics tool to analyze Python files for ethical and compliance risks.

## Inputs
- Python source files
- Policy or rules configuration

## Outputs
- Risk summary report
- Suggested remediation notes

## Usage
1. Run the tool against target files.
2. Review flagged issues and severity.
3. Apply recommended fixes and re-run checks.

## Notes
- Keep rule definitions up to date.
- Treat generated suggestions as advisory and validate before deployment.
